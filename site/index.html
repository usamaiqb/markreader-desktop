Read Markdown exactly as VS Code previews it

MarkReader is a fast, free desktop reader for .md files. Double-click a file and it opens with VS Code's preview styles, Mermaid diagrams and math. You don't need an editor.

Download View source

For Windows and Linux · About 5 MB · Free and open source (GPL-3.0)

Made for reading, not editing

Use it for READMEs, docs folders, notes and AI-written reports: anything you want to read without opening an IDE.

Looks like VS Code's preview

It uses the same stylesheets and markdown-it setup, so a document looks the same in MarkReader as in VS Code.

Diagrams, math and code

GitHub tables and task lists, Mermaid diagrams, KaTeX math and syntax highlighting for the common languages.

Live reload

Save the file in any editor, and the view updates without losing your scroll position.

Tabs and folders

Open a folder to browse its Markdown files in a sidebar. Your tabs come back on the next launch.

Outline and find

Jump between headings in the outline pane. Search the document with Ctrl+F.

Small and private

A native Tauri app of about 5 MB. It runs offline and has no telemetry and no account.

Technical documents render correctly

Flowcharts, sequence diagrams, equations and highlighted code all render, just like in VS Code. Light and dark themes follow your OS.

Open files from anywhere

MarkReader becomes the default app for .md files. If it is already running, new files open as tabs in the same window.

  1. 1Double-click any .md or .markdown file.
  2. 2Drag files or a folder onto the window.
  3. 3Use Ctrl+O for files and Ctrl+Shift+O for a folder.
  4. 4Run markreader notes.md from a terminal.
